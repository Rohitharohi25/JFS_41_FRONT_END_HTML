# 🌐 Personal Portfolio Website

A simple **Personal Portfolio Website** developed using **HTML** as part of my **Front-End Development Learning Series at Codegnan**.

This project was created to practice HTML fundamentals and understand how different sections of a webpage are structured.

## 📌 Project Overview

The portfolio website presents my personal information, education, achievements, projects, and contact details in a simple and organized layout.

## ✨ Features

* 👤 Personal introduction
* 🧭 Navigation menu
* 📝 About Me section
* 🏆 Achievements section
* 🎓 Education section
* 💻 Projects section
* 📧 Contact information
* 🔗 GitHub profile
* 📍 Location details
* ⭐ Font Awesome icons
* 📜 Declaration section
